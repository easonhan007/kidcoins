# KidCoins

儿童积分管理系统 - 帮助家长管理孩子的积分和奖励。

## 功能特性

- 📊 **积分管理** - 记录孩子的积分获取和兑换
- 👶 **多孩子支持** - 支持管理多个孩子的积分
- 🖼️ **头像设置** - 为孩子设置个性化头像
- 🌓 **暗夜模式** - 支持浅色/深色主题切换
- 📱 **响应式设计** - 支持桌面和移动设备
- 💾 **本地存储** - 数据保存在本地浏览器

## 技术栈

- React 19
- TypeScript
- Vite
- react-easy-crop (头像裁剪)
- pinyin (中文拼音搜索)

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
